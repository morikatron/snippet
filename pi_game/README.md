# π — 円周率100万桁を「足して10」で消していくゲーム

2007年発売のニンテンドーDS用ソフト『タシテン ＋たして10にする物語＋』のルールの原型は、
2006年3月に作られた「円周率100万桁から、足して10になる並びを消していく」という Mac 用の
試作でした。このディレクトリは、その試作のルールと「自動テスト」をブラウザ用に作り直した
ものです。ビルド不要の素の HTML / CSS / JavaScript です。

（経緯はモリカトロン エンジニアブログの記事を参照してください）

## ルール

- 窓には、残っている数字のうち先頭の10桁が見えている
- 窓の中の連続した並びで、合計が10の倍数になるところを選ぶと消える（合計0も含む）
- 消えたぶんは後ろから詰まってくる
- 盤面は円周率の先頭999,998桁（整数部の3を含む）。全部消したら上がり

999,998という半端な数には理由があります。1手で消える合計はかならず10の倍数なので、
全部消すには盤面全体の合計が10の倍数でなければなりません。円周率の先頭100万桁の合計は
4,499,936 で10で割ると6余り、先頭999,998桁でちょうど 4,499,930（10の倍数）になります。
つまり999,998は「合計が10の倍数になる、いちばん長い切り方」です。

## 自動テスト

「本当に最後まで消せるのか」を機械に確かめさせる機能です。窓の中の解を
「開始位置の昇順 → 終わり位置の昇順」で数え、いつも0番から試し、行き止まりになったら
一手戻して次の解番号を試す、という深さ優先の総当たりで、2006年の試作に組み込まれていた
ものと同じ動きをします。この探索は一度も行き止まらずに202,326手で完走します。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ本体 |
| `style.css` | 見た目 |
| `app.js` | ゲームと自動テスト（依存なし） |
| `pi_bcd.bin` | 円周率100万桁。1バイトに2桁の BCD 詰めで500,000バイト |
| `generate_pi.py` | `pi_bcd.bin` を自分で作り直すスクリプト（mpmath 使用） |

`pi_bcd.bin` はこのリポジトリ用に mpmath で計算し直したものです。BCD の詰め方
（1バイトに2桁、上位4ビットが先）は2006年の試作および製品と同じ形式です。

## ローカルで動かす

`fetch()` でデータを読むので、ファイルを直接開くのではなく Web サーバ経由で開きます。

```
python3 -m http.server 8000
# → http://localhost:8000/
```
